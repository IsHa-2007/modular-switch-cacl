# Calculator in c
This is a simple calculator program written in c language The project is created for learning basic programming concepts
## Features 
⁃ Addition 
⁃ Subtraction 
⁃ Multiplication 
⁃ Division 
⁃ Remainder(modulus)
⁃ average calculation
⁃ Uses switch case and loops
 ## Language Used ⁃ C programming language
 ## Note This project contains only source code. The program may not be compiled in this environment. It is meant for learning and practice purposes.
 ## How to Compile (Optional) If you have GCC installed:
 gcc calculator.c -o calculator /calculator
